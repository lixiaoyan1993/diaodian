# 叼点小程序 UI 设计系统

## 产品定位

叼点是给钓鱼人使用的标点地图和私人点库工具，核心场景是户外快速记录、回看复盘、查看公开标点和钓友验点。界面应像一个可靠的户外工具，不做营销感和装饰感过强的视觉。

## 视觉关键词

- 水域感：浅灰绿背景、白色信息面、蓝绿色地图/定位色。
- 可信度：分数、验点、收藏等信息要比装饰更醒目。
- 快速操作：记录页优先保证定位、钓法切换、保存按钮清晰可点。
- 克制社区感：大厅和验点强调“钓友贡献”，但不做热闹的信息流。

## 组件规则

- 卡片圆角统一 `8px`，用轻边框和低阴影，不做大圆角漂浮卡。
- 主按钮使用橘红色，地图/定位按钮使用蓝绿色，筛选选中使用深墨色。
- 不使用 emoji 作为 UI 图标；小程序内用文字徽标或 CSS 形状承载状态。
- 列表卡片优先展示：名称、钓法、鱼种、地址、可信分、验点/收藏数。
- 空状态必须给出下一步含义，不留空白页。

## 页面方向

- 标点大厅：公开标点浏览，顶部展示当前筛选和数量，列表/地图视图切换。
- 记点：快速表单，先钓法和定位，再补作钓细节，保存按钮固定在信息流末端。
- 标点详情：首屏突出名称、钓法、地址和可信分，操作按钮只保留验点与收藏。
- 验点：风险反馈必须像选择器一样清晰，颜色区分正向、普通、警示、风险。
- 我的点库：偏资料库，不做社区热闹感，重点是筛选和快速回看。
